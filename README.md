# ArchPilot AI

ArchPilot AI is an ML and RAG-based decision support system for recommending application architecture and deployment strategy.

## Project Title

ArchPilot AI: An ML and RAG-Based Decision Support System for Application Architecture and Deployment Recommendation

## Objective

The objective of this project is to recommend a suitable application architecture and deployment strategy based on application requirements.

The system can recommend:

- Monolithic Architecture
- Containerized Application
- Microservices Architecture
- Kubernetes Deployment

## Technologies Used

- Python
- Scikit-learn
- FastAPI
- RAG-style knowledge retrieval
- Docker
- Kubernetes
- GitHub Actions

## Input Features

- Users count
- Traffic level
- Team size
- Update frequency
- Number of integrations
- Security level
- Scalability need

## Output

- Recommended architecture
- API style
- Authentication suggestion
- Authorization suggestion
- Deployment suggestion
- RAG-based explanation
